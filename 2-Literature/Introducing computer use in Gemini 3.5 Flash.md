# Introducing computer use in Gemini 3.5 Flash

## Source Metadata

## Abstract / Summary
Computer use is now a built-in tool in Gemini 3.5 Flash rather than only a standalone computer-use model, enabling agents that see, reason, and act across browser, mobile, and desktop environments. DeepMind highlights stronger performance for long-horizon and enterprise automation tasks such as continuous software testing and knowledge work. Availability is via Gemini API and Gemini Enterprise Agent Platform. Safety measures include adversarial training against prompt injection plus optional enterprise safeguards that require confirmation for irreversible actions and can stop tasks when indirect prompt injection is detected, alongside sandboxing and human-in-the-loop guidance.
