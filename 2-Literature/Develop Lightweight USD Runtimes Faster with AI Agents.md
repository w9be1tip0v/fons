## Abstract / Summary
nanousd-labs (NVIDIA Omniverse Labs) enables developers to generate lightweight, specification-compliant USD runtimes from the Alliance for OpenUSD Core Specification using AI agents, avoiding adaptation of large legacy codebases. Agents parse and implement the formal contract; compliance is validated against specification-derived tests. Engineers keep architectural choices while agents automate spec-to-code work such as parsing, scene composition, and value resolution under custom memory, performance, and ABI constraints.
