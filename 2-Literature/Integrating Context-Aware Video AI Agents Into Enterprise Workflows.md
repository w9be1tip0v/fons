## Abstract / Summary
Extends NVIDIA Metropolis VSS and enterprise RAG blueprints with NemoClaw agent orchestration. HITL tools capture intent; LVS summarizes video; RAG retrieves policies/SOPs; report generation produces structured timestamped output that can auto-create Jira tickets and feed downstream systems. Moves from “what does this video show?” to coordinated action at scale. Partner examples: Computacenter predictive maintenance (footage-to-work-order ~19s), VAST Data real-time sports pipelines. Claims VSS analysis dominates runtime (~92%); orchestration overhead is small.
