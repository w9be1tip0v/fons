## Abstract / Summary
MM-ToolSandBox is a benchmark and evaluation framework for visually grounded tool-calling agents. It provides a stateful execution environment spanning 500+ tools across 16 application domains, supporting multi-image, multi-turn tasks with goal revisions, error corrections, and state mutations. The suite includes 258 human-verified nominal scenarios and 50 UI variants. Evaluating 12 models (4B open-weight to frontier proprietary), even the best model stays below 50% success; failure analysis attributes 53% of capable-model failures to incorrect information extraction from images despite correct workflows. Code: https://github.com/apple/ml-mmtoolsandbox
