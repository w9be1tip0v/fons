# Data for Agents

## Abstract / Summary
Building reliable agents is a data problem: software-engineering traces, tool-use failures, multi-step reasoning, retrieval, safety, user simulation, and workflow execution. The post argues open weights are necessary but not sufficient; datasets, curation choices, training recipes, and evaluation methods must also be inspectable. NVIDIA Nemotron open data products (including pretraining and post-training corpora, Nemotron-CC, math data, and Nemotron-Personas) and synthetic data are framed as ways to scale agent-relevant behaviors without exposing proprietary secrets. Interactive exploration via the Nemotron Post-Training v3 Prompt Atlas is highlighted so practitioners can inspect prompt mixtures for coding, safety, math, and agentic behavior.
