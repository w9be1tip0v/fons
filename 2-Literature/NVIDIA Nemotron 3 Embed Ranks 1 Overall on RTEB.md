## Abstract / Summary
NVIDIA releases Nemotron 3 Embed: open commercial embedding models for production RAG, agentic retrieval, code retrieval, and agent memory. Nemotron-3-Embed-8B-BF16 ranks #1 on RTEB (78.5% RTEB, 75.5% MMTEB Retrieval). 1B BF16 and NVFP4 variants target cost/latency and Blackwell throughput (2× vs BF16, 99%+ accuracy retention). Features include 32k context, multilingual + code retrieval, open weights/datasets/recipes, NIM microservice, and NeMo AutoModel fine-tune/distillation recipes. Better retrieval reduces downstream agent token cost on ViDoRe V3, BRIGHT, and BrowseComp-Plus.
