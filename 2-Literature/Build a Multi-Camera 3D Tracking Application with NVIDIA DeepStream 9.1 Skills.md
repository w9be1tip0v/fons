# Build a Multi-Camera 3D Tracking Application with NVIDIA DeepStream 9.1 Skills

## Source Metadata

## Abstract / Summary
DeepStream 9.1 adds AutoMagicCalib (AMC) and Multi-View 3D Tracking (MV3DT) plus 13 agentic skills for coding agents (Claude Code, Codex). MV3DT fuses multi-camera detections into a shared 3D frame with globally consistent IDs (PeopleNetTransformer/PeopleNet/RT-DETR, MQTT association, OSD/BEV/Kafka outputs). AMC automates intrinsic/extrinsic calibration from video instead of manual checkerboards (optional VGGT). JetPack 7.2 support; open reference apps on NVIDIA DeepStream GitHub. Bridges vision analytics with agent-driven pipeline deployment via natural-language prompts.
