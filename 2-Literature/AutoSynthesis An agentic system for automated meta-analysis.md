## Abstract / Summary
Quantitative evidence synthesis remains largely manual. AutoSynthesis is an end-to-end multi-agent system for automated meta-analysis: from a natural-language research question it formulates search, retrieves literature, screens studies, assesses full-text eligibility, extracts stats, computes standardized effect sizes, and runs random-effects meta-analysis, plus heterogeneity and risk-of-bias support. Output is a transparent PRISMA-aligned report. In application it screened 28+ studies and extracted 20+ quantitative claims; pooled estimates were similar to expert Hedges' g, suggesting scalable quantitative evidence synthesis for science, medicine, education, and policy.
